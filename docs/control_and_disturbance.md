# 控制与扰动 / Control and Disturbance

## 姿态控制模式 / Attitude control modes

- 关闭 / OFF：期望控制力矩为零，控制相关指标显示不适用。
- 默认 / Default：卫星使用动态推荐 PD，火箭使用动态推荐 LQR 状态反馈。
- 自定义 / Custom：可选 PD、PID 或 LQR。PID 提供三轴积分限幅与抗积分饱和；重新配置/重置会清空积分状态。

推荐值根据飞行器类型、三轴惯量和三轴执行机构力矩能力计算。火箭推荐值使用施加真值偏差后的惯量与推力能力。

## 卫星轨道控制 / Satellite orbit control

卫星的姿态控制和轨道控制是两条独立闭环：反作用飞轮根据姿态误差产生控制力矩；三轴微推力器根据名义/实际轨道的位置、速度误差产生平动力。轨道外环采用

`a_cmd = g(r_nom) - g(r_actual) - Kp·(r_actual-r_nom) - Kd·(v_actual-v_nom)`，

其中误差同时转换为 RTN/LVLH 分量供死区判断、曲线显示和 CSV 导出。合推力受用户设置上限约束，并按比冲扣减推进剂；推进剂耗尽后强制停止轨控。该控制器把卫星拉回既有名义轨道，不进行在线轨迹优化或轨道重规划。

## 火箭串级制导控制 / Launch-vehicle cascaded guidance and control

火箭控制不再只跟踪 CSV 姿态。启用轨迹制导后，位置/速度外环先依据轨迹偏差修正期望推力方向，再由姿态内环的 PD、PID 或 LQR 跟踪该方向。因此更改姿态控制方法或增益会改变姿态响应，并通过推力方向进一步影响实际轨迹。终端轨道制导仅进行反馈跟踪、自适应关机和有限补燃，不做在线轨迹优化。

## 持续扰动 / Persistent disturbances

除初始姿态/角速率扰动外，仿真可持续施加外扰：

- 卫星：恒定力矩、脉冲力矩、正弦力矩、随机力矩可同时启用；还可在指定时刻施加一次性 RTN/LVLH 速度脉冲，用于检验轨道恢复能力。
- 火箭：稳态侧风、有限时阵风、脉冲 ECI 外力、脉冲机体系力矩、随机力/力矩，可同时启用。

随机扰动使用固定种子和固定更新时间，因此相同设置可重复。设置在下一次开始或重置时进入动力学。
