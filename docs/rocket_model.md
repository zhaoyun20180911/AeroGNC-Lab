# 火箭模型 / Launch Vehicle Model

## 固定任务 / Fixed missions

火箭场景必须从文昌、西昌、卡纳维拉尔角三个发射场中选择一个，并从 300 km/28.5°、500 km/51.6° 两个固定圆轨道中选择一个。标称质量、惯量、推力、比冲、气动参数和 TVC 限制从任务数据读取并只读显示。

## 标称与实际 / Nominal and truth states

- 标称位置、速度和标量字段按时间线性插值；姿态用 SLERP，级段采用离散状态。
- 实际 ECI 位置、速度、姿态、角速度和质量从 CSV 首状态开始独立 RK4 积分。
- 用户只修改真值模型偏差，不改写标称 CSV：质量、惯量、推力、Isp、Cd、大气密度和 TVC 零偏。
- 平动包含球形地球引力、姿态/TVC 决定的推力、随地球旋转的大气相对速度、指数大气阻力和外扰力。
- 转动包含时变惯量刚体方程、发动机力臂、TVC、滚转 RCS 和外扰力矩。
- 推进剂流量为 `m_dot = -T/(Isp·g0)`；级间事件丢弃一级干质量，并保留载荷与二级干质量下限。

## 文件后轨道滑行 / Post-file orbital coast

标称文件结束后，标称末状态和实际末状态分别在二体引力下传播。推力和 TVC 控制力矩归零；实际状态不会重置或吸附到标称轨迹。爬升阶段的位置、横向、高度、速度和姿态跟踪误差在首次进入滑行段时冻结为“入轨快照”，不再把后续相位漂移误报为入轨精度；滑行段继续输出实际位置、速度、轨道高度与瞬时轨道根数。

## 轨迹制导与推进剂事件 / Trajectory guidance and propellant events

- 外环使用标称与实际 ECI 位置、速度偏差生成受限推力方向，随后转换为姿态指令；现有 PD/PID/LQR 控制器跟踪该指令并通过 TVC/RCS 执行。
- 位置增益、速度增益、最大姿态修正角和最大指令变化率均可在双语“轨迹制导”窗口配置，并在下一次开始/重置时生效。
- 一级、二级推进剂分别保存。实际质量由结构质量和两级剩余推进剂组成；任一级推进剂耗尽时，该级推力立即归零。
- 二级终端窗口比较实际轨道比能量与固定目标轨道；推力偏大时自适应提前关机，推力偏小时可在剩余推进剂与最大补燃时间约束内延长点火。
- 终端轨道指标相对固定目标轨道计算；实际关机后立即冻结入轨指标并进入独立二体滑行。
