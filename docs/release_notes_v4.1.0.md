# AeroSys Lab v4.1.0

本地功能版本，未上传 GitHub。

## 新功能

- 产品更名为 **AeroSys Lab｜航天系统综合仿真平台**。
- 三个顶层模块统一为“卫星姿轨控”“火箭上升入轨”“火箭一级回收”。
- 主窗口、技术视图、参数区与全部设置弹窗改为白底深色文字的浅色界面。
- 顶部新增“中文 / English”开关；界面按所选语言单语显示，按钮、下拉项、曲线、指标、提示和弹窗同步切换。
- 新增一级回收 RTLS 完整状态机、真值导航、ECEF/NED、在线返场修正、再入制导、四片栅格舵、动态着陆点火和滚动时域在线凸 QP。
- 默认一级分离状态改为 80 km 高度，并同步调整为 20 km 下场距离、600 m/s 北向速度、−150 m/s 向下速度、90 t 总质量、62 t 回收推进剂和 2.28 MN 等效发动机组。
- 新增回收三维技术视图、预测落点、阶段显示、实时曲线、30 项自定义参数、12 项汇总指标和专用 CSV。
- 新增分离状态文件接口以及六组标准回收自动测试。

## 验证

- `gnc_tests`：原卫星与火箭上升入轨 29 项回归测试通过。
- `recovery_tests`：六组标准工况全部通过完整状态序列并满足安全 TOUCHDOWN 门槛。
- 80 km 默认状态下，组合扰动工况落点误差约 0.023 m、垂直触地速度约 0.118 m/s。
- 输出文件：`build/Release/AeroSysLab.exe`。
