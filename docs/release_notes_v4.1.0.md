# AeroSys Lab v4.1.0

正式发布于 2026-09-14。

## 维护更新（2026-09-17）

- 修复中文模式下双语标签切换时丢失单位的问题，主参数区、曲线、姿态控制、轨道控制、轨迹制导、扰动设置和参数提示均保留实际单位。
- 偏心率、控制权重等无量纲参数，以及 QP 预测步数和最大迭代次数，现已明确标注。
- 单文件 EXE 与 Portable ZIP 已同步重新构建并更新。

## 下载方式

- **单文件 EXE（推荐）**：`AeroSys_Lab_v4.1_Windows_x64.exe`，适合绝大多数用户，下载后直接双击运行。
- **本地免安装部署包**：`AeroSys_Lab_v4.1_Windows_x64_Portable.zip`，内含 EXE、运行说明和 SHA-256 校验文件，适合归档、校验和本地分发。
- 两种产物功能相同，均不要求安装 Visual Studio、CMake 或 Microsoft Visual C++ 运行库。

## 新功能

- 产品更名为 **AeroSys Lab｜航天系统综合仿真平台**。
- 三个顶层模块统一为“卫星姿轨控”“火箭上升入轨”“火箭一级回收”。
- 主窗口、技术视图、参数区与全部设置弹窗改为白底深色文字的浅色界面。
- 顶部新增“中文 / English”开关；界面按所选语言单语显示，按钮、下拉项、曲线、指标、提示和弹窗同步切换。
- 新增一级回收 RTLS 完整状态机、真值导航、ECEF/NED、在线返场修正、再入制导、四片栅格舵、动态着陆点火和滚动时域在线凸 QP。
- 默认一级分离状态改为 80 km 高度，并同步调整为 20 km 下场距离、600 m/s 北向速度、−150 m/s 向下速度、90 t 总质量、62 t 回收推进剂和 2.28 MN 等效发动机组。
- 新增回收三维技术视图、预测落点、阶段显示、实时曲线、30 项自定义参数、12 项汇总指标和专用 CSV。
- 新增分离状态文件接口以及六组标准回收自动测试。
