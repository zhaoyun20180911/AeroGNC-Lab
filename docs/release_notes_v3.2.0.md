# AeroGNC Lab v3.2.0

卫星初始姿态状态参数版本 / Satellite initial attitude state release.

## 下载选择 / Downloads

- **Windows x64 免安装封装版（推荐）**：下载 `AeroGNC_Lab_v3.2_Windows_x64_Portable.zip`，解压后无需安装，双击 EXE 即可运行。
- **可编辑源码版**：下载 `AeroGNC_Lab_v3.2_Source.zip`，适合学习和二次开发；需要 Windows、Visual Studio 2022、CMake 和 C++ 开发环境。

## v3.2 更新 / What's new

- 卫星主界面参数区新增三轴初始姿态偏差：滚转、俯仰和偏航，单位为度。
- 新增三轴初始机体系角速度偏差：滚转、俯仰和偏航角速度，单位为度每秒。
- 六项参数全部采用中英双语，可直接编辑，并在下一次开始或重置时进入卫星姿态动力学。
- 卫星参数面板扩展为四行，新增字段与底部状态栏保持清晰间距；火箭参数面板维持原布局。
- README 主界面和设置功能截图已重新生成并更新为 v3.2。

## 主要功能 / Highlights

- 卫星六轨道根数、四类姿态任务、PD/PID/LQR 姿态控制、反作用飞轮和可编辑初始姿态状态。
- 卫星名义/实际独立轨道传播、RTN 六状态轨道控制、三轴微推力器、推进剂与一次性 Δv 扰动。
- 六个固定运载火箭任务、位置/速度轨迹制导外环、姿态控制内环、TVC/RCS、分级推进剂与自适应关机。
- 可交互三维技术视图、实时双语曲线、性能指标、扰动/摄动设置和 CSV 导出。
