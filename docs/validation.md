# 验证策略与结果 / Validation Strategy and Results

Release 配置执行 29 项自动测试，当前结果为 `29 passed, 0 failed`。覆盖范围：

- 四元数单位性、轴旋转、乘法顺序、矩阵/Euler 往返、`q/-q` 等价与 SLERP 归一化。
- 完整 3×3 惯量矩阵求逆、无力矩角动量守恒和恒力矩解析解。
- 六个经典轨道根数与 ECI 状态往返。
- 控制 OFF 隔离、PD/PID/LQR 选择、PID 积分限幅与抗饱和。
- 卫星四种姿态任务的有限性、可配置初始姿态/角速度状态、闭环收敛、飞轮力矩/转速限制。
- 卫星一次性 RTN 速度脉冲、名义/实际独立传播、六状态轨道闭环恢复、轨控推力限幅、推进剂消耗与耗尽强制停机。
- 卫星/火箭持续扰动的组合、时间窗和随机种子确定性。
- 任务仓库严格加载六个预设、轨迹完整性、时间插值与四元数连续性。
- 文件系统与内存/EXE 资源两种任务仓库加载路径返回相同的六个固定任务。
- 六个火箭任务均传播至标称文件末端并进入无推力轨道滑行，原始状态保持有限；爬升误差在滑行段标记为不适用。
- 同一任务分别传播 1 s 与 50 s 滑行后，入轨高度、速度与轨道根数误差快照保持一致。
- 火箭真值状态不吸附标称、干质量下限、TVC 限制与控制关闭时执行机构归零。
- 卫星和火箭 CSV 导出模式与样本数据。
- 两级推进剂独立耗尽、干质量保护和实际关机语义。
- 位置/速度外环对 +5% 推力偏差的闭环修正优于开环，且姿态内环增益变化会传递到实际轨迹。
- 六个固定火箭任务在 ±5% 推力偏差下均完成自适应关机/有限补燃，终端半长轴误差保持在自动验收阈值内。

此外使用 `scripts/capture_ui.ps1` 验收卫星/火箭主窗口运行状态并通过鼠标消息实际旋转三维相机，使用 `scripts/capture_settings.ps1` 验收姿态控制、卫星轨道控制、火箭轨迹制导、扰动和摄动窗口，使用 `scripts/capture_coast_ui.ps1` 验收入轨后的全球轨道视图及冻结指标。

七个任务数据在源目录与 Release 输出目录的 SHA-256 一致；构建过程未改写原始内容。

便携版额外执行 `--verify-embedded-data` 无界面资源自检，并在不带 `data/` 目录的隔离位置启动。PE 依赖检查仅包含 `COMCTL32.dll`、`COMDLG32.dll`、`dwmapi.dll`、`KERNEL32.dll`、`USER32.dll` 和 `GDI32.dll`，不依赖 `MSVCP*.dll`、`VCRUNTIME*.dll` 或外部 VC++ Redistributable。

复现命令 / Reproduce:

```powershell
cmake --build build --config Release --parallel
.\build\Release\gnc_tests.exe
```
